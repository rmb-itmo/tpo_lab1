## 1. Модульное тестирование разложения функции `arcsin(x)` в степенной ряд

### 1.1. Описание реализации

Функция `ArcSinSeries.compute(double x)` вычисляет значение арксинуса через ряд Тейлора:

$$ \arcsin(x) = x + \frac{1}{2} \cdot \frac{x^3}{3} + \frac{1 \cdot 3}{2 \cdot 4} \cdot \frac{x^5}{5} + \frac{1 \cdot 3 \cdot 5}{2 \cdot 4 \cdot 6} \cdot \frac{x^7}{7} + \dots $$


**Особенности реализации:**
- Обработка граничных значений: `x = 0, ±1` возвращают точные значения без итераций
- Для `|x| > 0.9` применяется преобразование: `arcsin(x) = sign(x)·(π/2 - arcsin(√(1-x²)))` для ускорения сходимости
- Критерий остановки: `|term| < ε`, где `ε = 1e-12` по умолчанию
- Максимальное число итераций: 100

### 1.2. Стратегия тестового покрытия

| № | Тип теста | Описание | Покрытие |
|---|-----------|----------|----------|
| 1 | Граничные значения | `x = 0, 1, -1` | Крайние точки области определения |
| 2 | Табличные значения | `x = 0.5, √2/2, √3/2` | Известные точные значения |
| 3 | Сравнение с `Math.asin()` | 7 значений в `[-0.99, 0.99]` | Общая корректность вычислений |
| 4 | Свойство нечётности | `arcsin(-x) = -arcsin(x)` | Математическое свойство функции |
| 5 | Исключения | `|x| > 1` | Обработка недопустимых входных данных |
| 6 | Монотонность | Пары `x₁ < x₂` → `f(x₁) < f(x₂)` | Поведение функции на интервале |
| 7 | Точность при разном `ε` | Сравнение `ε=1e-4` и `ε=1e-12` | Влияние параметра точности |
| 8 | Сходимость для малых `x` | `x = 0.01` | Быстрая сходимость ряда |
| 9 | Сходимость у границ | `x = ±0.999...` | Устойчивость при `|x| → 1` |
| 10 | Точность по диапазонам | Группировка по величине `x` | Равномерность качества вычислений |
